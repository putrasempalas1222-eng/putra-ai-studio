Contoh JavaScript

const response = await fetch(
  "https://api-mzmdqh3n6a-uc.a.run.app/chat",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": "API_KEY_KAMU"
    },
    body: JSON.stringify({
      prompt: "Halo PUTRA AI Studio"
    })
  }
);

const data = await response.json();

console.log(data);

Contoh Python

import requests

url = "https://api-mzmdqh3n6a-uc.a.run.app/chat"

headers = {
    "Content-Type": "application/json",
    "x-api-key": "API_KEY_KAMU"
}

payload = {
    "prompt": "Halo PUTRA AI Studio"
}

response = requests.post(
    url,
    headers=headers,
    json=payload
)

data = response.json()

print(data)

Kebijakan Privasi

Halaman ini menjelaskan data apa saja yang digunakan oleh PUTRA AI STUDIO, alasan data itu dipakai, serta tindakan yang dapat diambil jika terjadi pelanggaran penggunaan layanan.

Data Akun

Email, UID Firebase, status verifikasi email, API key, limit akun, dan status aktif/nonaktif dipakai untuk autentikasi, pengelolaan akun, serta akses layanan.

Data Perangkat dan Jaringan

Device ID, IP address, user agent browser, dan session ID dipakai untuk keamanan, pencegahan spam, deteksi penyalahgunaan, dan investigasi pelanggaran.

Data Percakapan

Prompt yang dikirim, histori chat, dan jawaban AI dapat disimpan untuk menjalankan layanan, menjaga konteks percakapan, dan memantau penyalahgunaan sistem.

Data Pemakaian

Jumlah request, limit bulanan, pemakaian harian, spam count, waktu request, dan catatan pelanggaran dipakai untuk menghitung kuota serta menjaga layanan tetap stabil.

Ulasan

Rating dan isi review yang dikirim user disimpan untuk evaluasi kualitas layanan dan perbaikan produk.

Pembayaran

Jika fitur upgrade dipakai, informasi paket, invoice, nominal, dan data QRIS yang diperlukan untuk proses pembayaran dapat diproses untuk menyelesaikan transaksi.

Tujuan Penggunaan Data

  • Membuat dan mengelola akun pengguna.
  • Menyediakan API key dan layanan chat AI.
  • Menghitung kuota, limit, dan penggunaan layanan.
  • Mencegah spam, penyalahgunaan, dan akses yang tidak sah.
  • Menangani laporan, ulasan, serta peningkatan kualitas layanan.

Pelanggaran dan Konsekuensi

  • Mengirim request terlalu cepat secara berulang.
  • Mengirim pesan spam, acak, atau pesan yang sama berulang kali.
  • Menyalahgunakan API key, mencoba mengganggu layanan, atau memakai sistem di luar tujuan wajar.
  • Mencoba mengakses akun, endpoint, atau data yang bukan miliknya.

Jika pelanggaran terdeteksi, sistem dapat memberi peringatan, membatasi akses, menonaktifkan API key, memblokir device/IP, atau melakukan banned permanen terhadap akun terkait.

Keamanan Data

Data sensitif admin dilindungi melalui autentikasi, verifikasi token server-side, dan aturan akses database. User biasa hanya dapat mengakses data yang memang diizinkan untuk akunnya sendiri.

Catatan

Dengan menggunakan layanan ini, pengguna dianggap memahami bahwa data teknis tertentu perlu diproses agar layanan dapat berjalan aman, stabil, dan sesuai aturan penggunaan.
